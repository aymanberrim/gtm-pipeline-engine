# Example reference page

A reference page carries the depth the skill body points to. It is opened when the body says so, not read cold.

## What belongs here

- A full scoring rubric with the real numbers (weights, thresholds, caps).
- Two or three worked examples: one clean case, one edge case, one that went wrong.
- Channel or segment variants of the play.
- The failure table: where this step usually leaks, and the guard that stops it.

## What does not belong here

- Anything the body already says.
- Tool walkthroughs, UI screenshots, vendor-specific setup.
- Dates, "recently", "this year".

## Shape

Start with a one-line purpose. Use tables for rubrics. Keep each worked example under 200 words. End with the two or three questions the operator should ask when the rubric gives an ambiguous answer.
