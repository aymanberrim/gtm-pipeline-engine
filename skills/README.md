# Skills

The skills in this engine, in the order a lead meets them. Each folder holds a `SKILL.md` spine and a `references/` directory with the rubrics, worked examples and failure tables. Format is validated by `tools/validate.mjs`.

| Stage | Skill |
|---|---|
| 1-target | market-entry-scorecard · regulatory-to-selling-points · stack-detection |
| 2-source | decision-maker-authority |
| 3-segment | segment-then-write |
| 4-engage | resource-magnet-funnel |
| 5-convert | zero-lead-lost · demo-booking-call |
| 7-learn | channel-operating-cadence |

Stage 6 (close) runs on library skills; the engine's contribution there is upstream (authority proof, stack tag, compliance pack).

New skill: copy `templates/skill/`, follow `AGENTS.md`, run the validator.
