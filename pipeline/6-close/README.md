# Stage 6 · Close

Run the deal from demo to signature with evidence instead of hope. Long cycles are normal for robots on a floor and agents in production; the engine keeps them moving with qualification gates, a pilot that ends in a decision, and a compliance pack that is ready before procurement asks.

## Input

- Booked demos with handoff packs from stage 5.
- The compliance pack (DPA, sub-processor list, conformity declaration, risk classification memo) from stage 1.
- The battlecard, the unit-economics numbers and the pricing model.

## Output

- A demo built from discovery notes that proves the one thing the buyer needs proven.
- A MEDDPICC gap audit per deal after every meaningful interaction, and a multi-threading plan.
- A pilot design with success criteria contracted before access and a conversion clock.
- A business case in ranges the buyer's finance team believes.
- A mutual action plan whose milestones are buyer evidence, covering security review, legal, works council and procurement in parallel.

## Exit criteria

- No deal advances a stage without the evidence score for that stage; qualify or kill at each gate.
- Every deal above a set value is multi-threaded (3+ named stakeholders, including the economic buyer).
- Every pilot has written success criteria, a start and an end date, and an instrumented activation metric.
- Compliance artifacts delivered within 48 h of the request.

## Metrics

| Metric | Definition | Default target |
|---|---|---|
| Demo held rate | Demos held / demos booked | 80%+ |
| Demo-to-pilot | Pilots started / demos held | 30%+ |
| Pilot-to-close | Signed / pilots ended | 50%+ |
| Cycle length | Demo to signature, median | Track; shorten with the mutual action plan |
| Single-threaded deals | Deals with 1 contact / open deals | under 20% |

## Skills

This stage runs entirely on library skills, which are strong here: `discovery-to-demo-bridge`, `meddpicc-gap-audit`, `multi-thread-deals`, `trial-poc-conversion`, `roi-business-case`, `mutual-action-plan-builder`, `procurement-navigation`.

The engine's own contribution to this stage is upstream: the authority proof, the stack tag and the compliance pack that make these skills work on the first try.

## Handoff to stage 7

Stage 7 receives the signed account with its why-they-bought evidence, and every lost deal with its evidence-based reason.
