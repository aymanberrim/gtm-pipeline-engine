# Stage 7 · Learn

Make the first customer a reference, make the channel a routine, and feed what the market said back into targeting and messaging. This is where the machine gets better every week instead of merely running.

## Input

- Signed accounts and lost deals from stage 6 with their evidence.
- The funnel metrics from every stage, the deliverability log, the cost of tools and time.
- The safety-net views and the scoring pipeline.

## Output

- A daily 15-minute and weekly 60-minute routine that empties the safety net, fixes the leakiest step, and reports to the CEO on one page.
- Onboarding run to first realised value on a clock; the first European reference documented.
- Win/loss evidence fed into the ICP rule, the battlecard and the group angles.
- A monthly refresh: ICP, stack-detection sweep of new accounts, market-entry scorecard re-check, compliance pack.
- Partner and expansion motions switched on when the entry mode or the account base calls for them.

## Exit criteria

- The CEO report goes out every week with the same five numbers and what changed.
- Scoring re-runs are idempotent (second pass changes nothing); human overrides live in their own table and survive re-scores.
- Every lost deal has an evidence-based reason, not a CRM dropdown value.
- At least one fix shipped per week on the leakiest funnel step, logged.

## Metrics

| Metric | Definition | Default target |
|---|---|---|
| Cost per demo | (tools + time) / demos booked | Under 10% of a demo's expected value |
| Time to first value | Signature to first realised value | Track; shorten monthly |
| Fixes per week | Logged funnel fixes | 1+ |
| Reference count | Customers willing to take a call | 1 within 90 days of first signature |
